# 👤 V5 Apollo Avatar (Capitania #12)
**Holding V5 Apollo · Agência Central de Identidades Digitais & Personagens Consistentes**

---

## 📖 Visão Geral
O **V5 Apollo Avatar** é o registro civil soberano de atores e personagens digitais da Holding V5 Apollo. Ele resolve a consistência visual 360º (Turnaround multi-ângulo), o clone vocal oficial e o perfil psicológico para que um único personagem possa atuar simultaneamente no V5 Broadcaster, V5 Prisma, V5 Sound, V5 Edit e V5 Finders.

- **Porta Local:** `http://localhost:3010`
- **Ambiente:** Next.js 14.2.35 (App Router) + Tailwind CSS + Lucide Icons + TypeScript
- **Integração:** Conectado à `https://api.v5apollo.com` para geração de imagens e clonagem vocal.

---

## 🚀 Como Iniciar Localmente

```bash
# Entrar na pasta do projeto
cd "E:\MEUS PROGRAMAS\V5_APOLLO_SITES\V5_Apollo_Avatar"

# Instalar dependências
npm install

# Iniciar servidor local na porta 3010
npm run dev -- -p 3010
```
